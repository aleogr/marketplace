# Pinned so that CI and a Claude Code session run the same versions.
#
# playwright is held at 1.56.0 on purpose: each Playwright release is built
# against one exact Chromium revision, and the cloud environment ships a single
# preinstalled one (1194) that it does not replace. 1.56.0 is the release built
# against that revision, so a newer Playwright would have no browser to drive in
# a session. `make e2e` checks this before running, and .github/dependabot.yml
# holds the pin, because CI downloads its own browser and therefore can neither
# fail on the mismatch nor protect against it.
#
# psycopg is how the suite creates, seeds and tidies its own PostgreSQL
# database (e2e/database.py). Everything else it needs comes from the standard
# library, so there is no third-party HTTP client to keep up to date for a few
# requests.
playwright==1.56.0
psycopg[binary]==3.2.10
pytest==9.1.1
